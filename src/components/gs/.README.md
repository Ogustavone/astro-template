## Componentes template | Uso

### Fab.astro
Botões flutuantes de contato no canto inferior direito.

```astro
---
import Fab from "@/components/gs/Fab.astro"
import whatsapp from "../assets/icons/whatsapp.svg";
import email from "../assets/icons/email.svg";
---

<Fab links={[
  { href: "https://wa.me/5555912341234", icon: whatsapp, label: "WhatsApp", class: "bg-green-500" },
  { href: "mailto:email@gmail.com", icon: email, label: "E-mail", class: "bg-red-500" },
]} />
```

### Reels.astro
Player de vídeos verticais estilo Reels.

```astro
---
import Reels from "@/components/gs/Reels.astro"
import logo from "../assets/logo.png";
---

<Reels
  account={{ name: "@minhaempresa", avatar: logo }}
  reels={[
    {
      src: "/videos/reel-1.mp4",
      caption: "Veja como funciona nosso atendimento.",
      cta: { label: "Saiba mais", href: "/servicos" },
    },
    {
      src: "/videos/reel-2.mp4",
      caption: "Orçamento em menos de 24h.",
      cta: { label: "Pedir orçamento", href: "https://wa.me/5555912341234" },
    },
  ]}
/>
```

Para rolar até um reel por fora, use `data-goto="n"` (começa em 0) em qualquer elemento dentro do `<main>`:

```astro
<button data-goto="1">Ver depoimento</button>
```

### Bubbles.astro
Bolhas decorativas de fundo (só CSS).

```astro
---
import Bubbles from "@/components/gs/Bubbles.astro"
---

<section class="relative">
  <Bubbles count={12} color="#f9a8d4" />
  <div class="relative z-10">Conteúdo</div>
</section>
```
- O pai precisa de `relative` e o conteúdo de `relative z-10`.

### Terminal.astro
Simulador de terminal Unix interativo com animação de digitação de comandos e exibição de outputs, otimizado para SEO, acessibilidade e performance (sem quebra de layout).

```astro
---
import Terminal from "@/components/gs/Terminal.astro";
---

<Terminal
  title="Terminal — deploy"
  host="gustavo"
  typingSpeed={40}
  delayBetweenCommands={800}
  loop={true}
  commands={[
    "npm run build",
    "git commit -am 'feat: add seo features' && git push",
    "echo 'Deploy completo!'"
  ]}
  outputs={{
    0: [
      "▶ astro build",
      "✓ Completed in 1.42s",
      "Generating static routes..."
    ],
    1: [
      "Enumerating objects: 5, done.",
      "To ://github.com",
      "   a1b2c3d..e5f6g7h  main -> main"
    ]
  }}
/>
```

### Reveal.astro
Componente utilitário para animação de scroll suave (fade-in com deslocamento vertical). Ele observa a entrada do elemento no campo de visão do usuário (viewport) de forma otimizada usando uma única instância do IntersectionObserver.

```astro
---
import Reveal from "@/components/gs/Reveal.astro";
---
<Reveal class="duration-700 delay-200">
  <div class="p-6 bg-neutral-900 rounded-lg">
    <h2 class="text-xl font-bold text-white">Este conteúdo vai surgir na tela</h2>
    <p class="text-neutral-400">Efeito aplicado ao rolar a página para baixo.</p>
  </div>
</Reveal>
```

### FabMenu.astro
Menu flutuante expansível (Floating Action Button) para ações de contato rápidas. Suporta links externos, disparadores de aplicativos (tel:, whatsapp, mailto:) e aceita tanto imagens estáticas quanto imports de metadados do Astro de forma nativa.

```astro
---
import FabMenu from "@/components/gs/FabMenu.astro";
import iconWhatsapp from "../assets/icons/whatsapp.svg";
import iconEmail from "../assets/icons/email.svg";
---

<FabMenu
  side="right"
  buttonClass="bg-emerald-600 hover:bg-emerald-700 shadow-emerald-600/30"
  links={[
    { 
      label: "Chamar no WhatsApp", 
      href: "https://wa.me", 
      icon: iconWhatsapp 
    },
    { 
      label: "Enviar E-mail", 
      href: "mailto:gscorrea@gmail.com", 
      icon: iconEmail,
      newTab: false 
    }
  ]}
/>
```

### GlowBg.astro
Fundo decorativo moderno composto por esferas de luz fluidas e animadas (aurora orbs). Ideal para criar interfaces imersivas ou no estilo dark mode.

```astro
---
import GlowBg from "@/components/gs/GlowBg.astro";
---

<!-- Uso padrão em layouts escuros -->
<GlowBg 
  opacity={0.25} 
  colors={["#10b981", "#06b6d4", "#6366f1"]} 
/>
```
